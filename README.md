# Bizdwaar

**AI-powered digital launch companion for micro-businesses | GoDaddy Inclusive Innovation Hackathon 2026**

> *Your business's doorway to the digital world.*

---

## What it does

Bizdwaar lets a micro-business owner describe their business in plain language. Claude structures that description into a reviewed catalogue, the owner approves only what is accurate, and the result is a mobile-friendly public storefront with a working customer enquiry route.

**Core demo flow:**
1. Owner enters a plain-language business description
2. Claude drafts a structured profile and product catalogue
3. Missing facts (price, size, ingredients) surface as explicit questions — never guessed
4. Owner reviews, edits and approves only what is true
5. Owner publishes; a shareable storefront goes live
6. Customer submits an enquiry; owner receives an email

## Local setup

```bash
# 1. Clone
git clone https://github.com/sakshi13-m/BizDwaar.git
cd BizDwaar

# 2. Install
npm ci

# 3. Configure environment
cp .env.example .env
# Fill in real values in .env (never commit it)

# 4. Run dev server
npm run dev

# 5. Production build check
npm run build
npm start
```

## Environment variables

See `.env.example` for the full list. Secrets (`ANTHROPIC_API_KEY`, `MONGODB_URI`, `SMTP_PASS`, `OWNER_ADMIN_TOKEN`, `COOKIE_SECRET`) are server-only and must never be prefixed with `VITE_`.
